
# Lotto Number Generator

## Overview

A simple web application to generate random lottery numbers with theme support and partnership inquiries.

## Features

*   Generate 6 unique random numbers between 1 and 45.
*   Display the generated numbers in ascending order.
*   A button to trigger the number generation.
*   Dark/Light Mode toggle with persistence.
*   **Partnership inquiry form powered by Formspree.**
